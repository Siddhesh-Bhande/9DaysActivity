# 9DaysActivity: Daily Habit and Wellness Tracker

An interactive front-end web application tracking daily activities, workout benchmarks, and productivity milestones over a structured 9-day challenge cycle.

## Features

- **Activity State Tracking**: Real-time logging of daily workout completions, habit goals, and active timers.
- **Dynamic Scheduling**: Interactive cards loading activities programmatically via modular JavaScript modules.
- **Responsive Interface**: Polished CSS3 layout adapting across mobile devices and desktop monitors.

## Project Structure

```
9DaysActivity/
├── docs/
│   └── Description.md     # Detailed activity list and curriculum description
├── activities.js          # Activity catalog and configuration definitions
├── app.js                 # Event listeners, state handlers, and DOM mutations
├── index.html             # Application markup and card layouts
├── styles.css             # Theme tokens, card animations, and responsive styles
├── .gitignore             # OS ignore rules
├── LICENSE                # MIT License
└── README.md              # Application overview and execution instructions
```

## Running the Application

Open `index.html` in any modern web browser or run via static server:
```bash
npx serve .
```
